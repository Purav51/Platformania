Platformania

Overview:
A 2D platformer developed in Unity 6 as part of my game development portfolio. The project began by following the GameDev.tv Unity course and was later extended with original gameplay features and level design improvements.

Features:
- Three playable platforming levels
- Coin collection and score tracking
- Hidden collectibles encouraging exploration
- Multiple paths through levels
- Optional pacifist playstyle
- Main menu and startup screen
- Final score summary showing maximum achievable score
- Enemy combat using projectile attacks
- additional feature planned: new enemy type, secret level inspired from path of pain (Hollow knight)

Technologies:
- Unity 6000.3.9f1
- C#
- Tilemaps
- Cinemachine
- Unity UI

Controls:
- Move: A (left) D (right)
- Jump: Space
- Climb ladders: W (up) S (down)
- Shoot (left mouse button)

Running the game:
Download the ZIP from the repository and run Platformania.exe inside the Game folder.
